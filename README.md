# Go 后端 + Agent 优选资料路线

唯一入口：[学习系统.html](./学习系统.html)

## 这是什么

这是参照小林 Coding 公开训练营流程整理的“资料编排”，不是自写教材：

- 每周只给 1 个主资料和最多 1 个补充资料；
- 优先官方文档、正式大学课程和长期维护的高口碑项目；
- 每份资料标注本周精确范围、验证依据和适用限制；
- 免费优先；需要注册或少量 API 费用会明确标记；
- Go 后端是主线，Agent/RAG/MCP 位于后半段。

## 页面

- 本周资料：唯一执行入口。
- 优选资料库：20 项经过筛选的完整课程和网站。
- 52 周路线：查看小专项、项目和阶段复盘顺序。
- 筛选规则：说明保留和淘汰依据。

旧版页面均保存在 archive-v1，仅供追溯。
